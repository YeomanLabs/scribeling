Step-by-step guide

Set a device's Autopilot group tag

Find an enrolled device in the Intune admin center and change its group tag, so it picks up the right deployment profile on its next reset.

Before you start

  • Intune Administrator role, or a custom role with Enrollment programs write access
  • The device serial number

Device Enrollment

1

Open the Intune admin center at https://intune.microsoft.com/#home ↗

2

Select Devices in the left menu

3

Under Device onboarding, choose Enrollment

Locate Autopilot Device

4

Open Devices under Windows Autopilot

5

Search for the device serial number

The serial is on the label under the laptop, or run wmic bios get serialnumber.

Update Device Details

6

Set Group tag to Corp-Standard

The group tag decides which dynamic group, and so which deployment profile, the device lands in.

7

Select Save

8

Wait for the change to sync

Group tag changes can take up to 15 minutes to sync to Autopilot.
